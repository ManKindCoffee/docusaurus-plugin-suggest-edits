# Welcome

This site shows **docusaurus-plugin-suggest-edits** in action.

Scroll to the bottom of this page and select **Suggest an edit**. An editor opens with this page's Markdown. Change something, review the difference, and submit. On a configured site, your suggestion becomes a pull request for the docs team to review.

## Things to try

- Fix a typo in this paragraph: there's one in teh word "the".
- Open [Components](./guides/components.mdx) and change the text inside a tab.
- Open [Maths](./guides/maths.mdx) and adjust a formula.
- Open the [Changelog](./excluded/changelog.md). It's excluded, so it has no button.

## What you can't change

Readers can only change text. The server rejects any suggestion that changes the page's settings at the top, its imports, its components or any `{…}` expression. That stops a suggestion from adding code that runs when the site is built.
