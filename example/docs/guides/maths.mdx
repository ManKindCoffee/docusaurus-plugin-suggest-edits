# Maths

The plugin's safety check understands maths written with `remark-math`, so readers can correct formulas.

The quadratic formula gives the roots of $ax^2 + bx + c = 0$:

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

The expression under the square root, $b^2 - 4ac$, is the discriminant. When it's negative, there are no real roots.
